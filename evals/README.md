# Evals

This folder is for recording future Wondermint skill evaluation evidence.

Do not run Wondermint skill tests unless explicitly asked. When live evaluation
is requested, follow `repo-workflows/live-eval.md`.

## Folders

- `scorecards/`: version-level summaries and quality ratings.
- `logs/`: raw notes, transcripts, screenshots, API observations, and other evidence.
- `templates/`: reusable formats for future evaluations.

## Version Evidence

When a version is evaluated:

1. Save raw evidence under `evals/logs/vX.Y.Z/`.
2. Create a scorecard under `evals/scorecards/vX.Y.Z.md`.
3. Update `PROGRESS.md` with the outcome and next recommended work.
4. Tag the version only after the scorecard says it is usable, unless the owner explicitly asks otherwise.
