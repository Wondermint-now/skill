## Better Auth Scope

`/api/auth/*` is generated by Better Auth and configured in `src/auth/better-auth.config.ts`.

Configured capabilities:

- email/password auth
- email verification
- password reset/change/set flows
- Google OAuth
- bearer token auth
- two-factor auth
- magic links with `disableSignUp: true`
- API keys with `mk_live_` in production and `mk_test_` outside production
- device authorization with `verificationUri: /device`, 30 minute expiry, 5 second poll interval, 8 character user code
- custom device ownership plugin

Do not treat this file as the exact Better Auth route list. Before adding `/api/auth/*` endpoints to the Wondermint skill, verify the generated route list from the running backend or Better Auth's versioned docs.

## Middleware Messages

Turnstile middleware can return:

```json
{ "error": "Turnstile token required" }
```

```json
{ "error": "Turnstile verification failed" }
```

Password strength middleware can return:

```json
{ "code": "WEAK_PASSWORD", "message": "Password is required" }
```

Other possible weak-password messages:

- `Password must be at least <min> characters`
- `Password must be at most <max> characters`
- `Password must contain at least one uppercase letter`
- `Password must contain at least one lowercase letter`
- `Password must contain at least one number`

Better Auth hooks can also reject signup or magic-link flows with messages such as:

- `This invite code is assigned to a different email address.`
- `Registration limit reached. A valid invite code is required to sign up.`
- `Your access is pending approval. Please wait for your invitation to be confirmed.`
